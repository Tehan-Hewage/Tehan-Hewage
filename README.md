## 👨‍💻 About Me

Hello! I'm **Tehan Hewage**, a passionate **Software Engineering Student & Full-Stack Developer** currently pursuing **Computer Systems and Network Engineering**. 

I specialize in crafting high-fidelity interactive web applications, autonomous AI agent integrations, and scalable cloud-backed architectures. Whether it's building multilingual MCP shopping assistants, custom SaaS link builders, or multi-agent routing tools, I love transforming complex ideas into elegant, user-centric software.
